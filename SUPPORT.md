# Support

- **Questions** go to [GitHub Discussions](https://github.com/insane-kane/win-llmtop/discussions).
- **Bugs** go to issues, using the bug report form. Every bug report should include the output of `win-llmtop --check`.
- **Vulnerabilities** go through the process in [SECURITY.md](SECURITY.md); do not report them in public issues or Discussions.

## What to include

Bug reports should include the output of `win-llmtop --check`, along with the details the bug form asks for: the win-llmtop version, the Windows version, the llama.cpp build, and whether the server is in router or single-model mode.
